B-1 LOOKUP AND ROUTING - TEST QUESTIONS
=======================================

Twenty questions that exercise the retrieval router (derivation, lookup or
abstain), the lookup router's tables, each lookup template, and the edge
cases between them. Each line gives where the question should go and what the
answer should be.

Run one with:
  PYTHONPATH=src python -m agents.main --ask "<question>"

QUESTIONS
---------

Lookup: checkpoints (status, verdict, zone, route order)
    1. Was a6_back completed in the latest run?
       -> lookup: checkpoints                     OK   status, with the verdict (or MISSED)
    2. Which zone is a3_back in?
       -> lookup: checkpoints                     OK   its zone, per run
    3. Which checkpoints are in rowA_back in the latest run, in route order?
       -> lookup: checkpoints                     OK   the list, in route order
    4. What was a1_back's result on 19/8/2026?
       -> lookup: checkpoints                     OK   every run that day, status and verdict

Lookup: readings (values, and why one is missing)
    5. What was the temperature at a3_back in the latest run?
       -> lookup: checkpoint_readings             OK   the value and when it was read, cited
    6. Show the accelerometer values at a1_back in the latest run.
       -> lookup: checkpoint_readings             OK   all five accelerometer fields
    7. Why is there no PM2.5 reading at a3_back in the latest run?
       -> lookup: checkpoint_readings             OK   the reason (sps30_ok=false), shown uncited
    8. What did the sensors record at home in the latest run?
       -> lookup: checkpoint_readings             OK   every field, a value or a reason

Lookup: evidence (images drawn in the PDF)
    9. Which images were taken at a3_back in the latest run?
       -> lookup: evidence                        OK   the image paths, images drawn
   10. Show the thermal images in rowA_back in the latest run.
       -> lookup: evidence                        OK   thermal images only
   11. Are there any images for a6_back in the latest run?
       -> lookup: evidence                        OK   its images, or its status and none

Lookup: zones
   12. Which zones did the route cover in the latest run?
       -> lookup: zones                           OK   every zone, in route order
   13. Which zone comes after rowA_back on the route?
       -> lookup: zones                           OK   the next zone

More than one table
   14. What was a3_back's status and its temperature in the latest run?
       -> lookup: checkpoints + checkpoint_readings   OK   both, in one answer

Boundary: the same place, but a figure worked out (derivation)
   15. Which checkpoints failed and which were missed in the latest run?
       -> derivation: condition count (D2)        OK   failed and missed, listed apart
   16. Did a3_back go over the temperature limit in the latest run?
       -> derivation: threshold comparison (D1)   OK   over or not, and by how much
   17. What was the highest temperature in rowA_back in the latest run?
       -> derivation: maximum per zone (D5)       OK   the maximum and the checkpoint

Should abstain
   18. Why was the particulate sensor faulty at a3_back?
       -> abstain                                 ABSTAINED   asks for a cause
   19. What was the temperature at a3_back on 10 September 2026?
       -> lookup, then the router abstains        ABSTAINED   no run on that date
   20. What was the temperature at rowZ_back in the latest run?
       -> lookup, then the router abstains        ABSTAINED   not a zone in the records

WHAT EACH ONE TESTS
-------------------
- Loose names: "home" (8) is both a zone and a checkpoint; the router must
  put it in the right field.
- A complete answer: 11 must still answer when a checkpoint has no images,
  with its status instead of nothing.
- Several SQL writer steps in one answer: 14.
- Missed is not failed: 15 must keep inspected-and-failed apart from
  never-reached.
- The retrieval router's boundary: 16 and 17 name one checkpoint or zone but
  ask for a figure, so they go to derivation, not lookup.
- The prose writer: nearly every question names a checkpoint, so every
  lead-in checks that it writes "this checkpoint" and never the name.
